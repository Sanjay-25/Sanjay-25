# Funding verification handoff

1. Unzip this folder somewhere on your machine.
2. Open it in Claude Code (desktop app: open the folder; terminal: `cd` into it and run `claude`).
3. Paste the contents of PROMPT.txt.

Files
- CLAUDE.md: the full instructions, including the funding source hierarchy. Claude Code reads it automatically.
- companies.csv: 1,335 companies with website, founders, LinkedIn/X links, YC page and Tracxn leads.
- output_template.csv: the columns for results.csv.

When it finishes, upload results.csv back into the chat and it gets merged into the master sheet.
