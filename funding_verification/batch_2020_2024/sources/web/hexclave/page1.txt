Hexclave is an open-source user infrastructure platform. It handles the parts of a product that revolve around users: authentication, teams, payments, emails, analytics, and related building blocks. The project is designed to let teams start quickly on hosted cloud and keep their data exportable and self-hostable.. The project began with a focus on open-source user management: sign-in, account settings, email verification, user components, hooks, and an administrative dashboard. It now presents those capabilities as Hexclave, a broader catalog of modular apps built around a shared user model.. Hexclave is open source and welcomes contributions. The repository describes a MIT / AGPLv3 license split for SDKs and server components, and its documentation and code are available publicly on GitHub. Developers can read the docs, start a project in the dashboard, or run the platform on infrastructure they control.. Learn more in the documentation or explore the open-source repository .. . .
