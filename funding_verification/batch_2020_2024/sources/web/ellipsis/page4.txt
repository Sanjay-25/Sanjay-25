We've raised a $2M seed round to support our mission of automating tedious engineering tasks. The round includes participation from Twenty Two Ventures, Four Cities Capital, Garage Capital, Amino Capital, Transpose Platform Management, Pioneer Fund, and others. Y Combinator leaders including Dalton Caldwell, David Lieb, Garry Tan, Brad Flora, and Gustaf Alstromer also backed the round.. Adoption so far. Over 90 companies across industries now use Ellipsis for automated code reviews and bug fixes. According to our data, teams using Ellipsis merge pull requests 13% faster than those without AI code reviews.. What is Ellipsis?. Ellipsis is an AI developer tool that automatically reviews code and fixes bugs on pull requests. It uses LLM agents to identify logical errors and security issues and to enforce team style guides. Developers can tag @ellipsis-dev to have Ellipsis implement fixes. Ellipsis executes the code it generates, like a human would, so you get working, tested code directly from GitHub or GitLab..
