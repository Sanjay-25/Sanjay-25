Corgea, the leading automated code security platform, is excited to announce its integration with GitLab, the popular web-based DevOps lifecycle tool. This integration allows developers to seamlessly incorporate Corgea’s advanced security scanning and auto-remediation capabilities into their GitLab workflows, ensuring that their code remains secure throughout the development process. It is part of Corgea developer experience .. What is the Corgea GitLab Integration?. The Corgea GitLab Integration is a powerful tool that enables developers to automatically scan their code repositories hosted on GitLab for security vulnerabilities. Corgea’s state-of-the-art scanning engine, BLAST , analyzes the code and identifies potential security risks, such as business logic flaws, authentication issues, and other common vulnerabilities. Scans can be codebase wide (full) and can be done on Merge requests.. Once vulnerabilities are detected, Corgea’s intelligent auto-remediation system generates secure code fixes tailored to each identified issue. These fixes can be automatically applied to the codebase, ensuring that the vulnerabilities are addressed promptly and efficiently. For the PR conversation layer across source-control tools, see Corgea Agent .. . How Does the Corgea GitLab Integration Work?. The integration process is straightforward and can be completed in just a few simple steps:. . Connect Corgea to GitLab : Start by connecting your GitLab account or organization to Corgea. This can be done through the Corgea web interface by following the instructions in the documentation . You can also choose to scan Merge Requests using Corgea.. . Configure Repositories: Select the GitLab repositories you want Corgea to scan and monitor for security vulnerabilities.. . Scan and Remediate : Corgea will automatically scan your code repositories whenever new Merge Requests are opened. If vulnerabilities are found, Corgea will generate secure code fixes and provide you with the option to apply them directly to your codebase.. . Review and Merge : Once the fixes have been applied, you can review the changes and merge them into your main codebase, ensuring that your code remains secure and compliant with industry standards.. . By integrating Corgea with GitLab, developers can streamline their security processes, reduce the risk of vulnerabilities making their way into production environments, and ultimately deliver more secure and reliable software to their users.. Get Started with the Corgea GitLab Integration. To start using the Corgea GitLab Integration, visit the Corgea website and follow the setup steps in the documentation.
