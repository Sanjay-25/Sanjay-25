What is Locus Pro? + Locus Pro gives an AI agent one connection to a catalog of paid APIs and proprietary data sources. The agent can discover the right capability for a task and use it from one balance instead of relying on separate provider accounts, subscriptions, and API keys.. Related: Browse the agent tool catalog . How does my agent find new tools? + It searches the Locus Pro catalog by the outcome it needs—not by a provider name it already knows. That lets it discover specialized capabilities for research, enrichment, verification, finance, voice, and more while the workflow is still running.. Related: Browse the agent tool catalog . Do I need accounts or API keys for every provider? + No. You connect the agent to Locus Pro once. Locus Pro handles access to supported providers, so the agent does not have to stop and ask you to create another account, choose another plan, or copy another API key.. Related: How Locus Pro connects . How is this different from buying API subscriptions directly? + Locus Pro draws metered usage from one prepaid balance.
