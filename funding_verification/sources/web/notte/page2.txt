See detailed pricing and rate limits . . . . . . . Frequently asked questions. What is Notte? + − Notte is a browser infrastructure platform for AI agents. It provides cloud browser sessions, browser agents, serverless browser functions, credential vaults, browser profiles, CAPTCHA handling, Playwright/Puppeteer/CDP compatibility, replays, and observability for production web automation.. Read the full explainer What are the main features of Notte? + − Notte's main features are managed cloud browser sessions, AI browser agents, serverless browser functions, browser profiles, credential vaults, proxies, CAPTCHA handling, live view, session replays, observability, file storage, and compatibility with Playwright, Puppeteer, Selenium, and CDP-based tooling.. How is Notte different from Browserbase, Browserless, or similar infra tools? + − Browserbase and Browserless give you remote browsers. You still need to build agents, handle auth, manage proxies, and deploy your scripts somewhere. Notte ships all of that as one platform, with compute running next to the browser for zero-latency automation. See how we compare on speed, reliability, and cost at browserarena.ai.. How is Notte different from BrowserUse, Skyvern, or other agent frameworks? + − Agent frameworks provide the reasoning loop. Notte provides the production stack around it: managed browsers, credentials, browser profiles, proxies, CAPTCHA handling, replays, observability, and deployment. You can use Notte's agents or bring your own framework on top of Notte infrastructure.. What browsers and automation frameworks are supported? + − Playwright, Puppeteer, Selenium, browser-use, Stagehand, and anything that connects via CDP. Works with Python, TypeScript, or Node.js.. Does Notte work with Playwright? + − Yes. Notte supports Playwright through CDP, so teams can connect Playwright to managed Notte cloud browser sessions while using Notte for profiles, proxies, CAPTCHA handling, live debugging, replays, and production deployment..
