Before you connect. Do I need an account with each provider? No. APIs in the Orthogonal catalog use your Orthogonal account and balance. We handle the provider integrations and billing, so you can use one key across providers.. Can I use Orthogonal with my existing agent? Yes. Coding agents can follow the instructions in our skill file . For Claude, Cursor, and other MCP clients, add our MCP server . If you’re building your own agent, use the REST API or CLI with your existing model and framework.. How is usage priced? Each endpoint has a price listed in the API catalog . Some prices are fixed; others depend on the request. Add credits to one balance and use them across providers. Orthogonal has no monthly platform subscription.. What does the unified API handle? Orthogonal handles tool discovery, authentication, and billing. Each provider’s endpoints still have their own inputs and response data.
