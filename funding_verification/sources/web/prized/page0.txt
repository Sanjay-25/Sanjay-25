What does it cost? + Plans run from $10 to $1,000 a month and land as credit. Boxes bill by the hour against it, so a Small at $100 a month is about $0.14 an hour awake, and a paused box costs only its disk. New workspaces get $30 of free credit to start, no card needed.. Which agents can I run? + Claude Code and Codex come preinstalled, Cursor installs on demand, and any other CLI agent installs the way it would on any Linux machine. prized setup copies your sign-ins to the box, so agents run on the plans you already pay for, and nothing they do is metered.. Does it work with the Claude and ChatGPT desktop apps? + Yes. Both connect to the box over SSH, and prized setup puts the box in your SSH config, so you add it by name in the app and work on it from there. The ChatGPT app on your phone connects too, with no Mac in the loop.. Can I use it from my phone? + Yes. The dashboard’s terminal runs in any browser, your phone’s included, and the box page issues a phone access password that the ChatGPT app uses to connect straight to the box, with no laptop in the loop. Whatever you reach it from, it is the same box and the same session.. What happens when I close the laptop? + Whatever runs on the box keeps running: dev servers, tmux sessions, and agents started with prized agents run. Reconnect and you are where you left off. The one exception is a task a desktop app is driving over SSH, which stops when your Mac sleeps, so start long runs on the box.. Where do my files live? + On the box’s encrypted disk, mirrored into a folder on your machine by two-way sync, so your editor and git tools work on a real local copy. Snapshot the disk from the dashboard before risky changes, and restore a snapshot into a new box any time.. Can I change the size later? + Yes, from the box’s dashboard page. The box restarts at the new size with its files intact and bills at the new rate from that moment. Seven sizes, from 2 vCPU and 2 GB to 32 vCPU and 128 GB.. Do I have to install anything on the box? + No. A box boots in about a minute with the agents, sync, and port mirroring ready.
