WHERE THE EMAIL GOES: POST to our own endpoint, api/subscribe.py in the attio-automations repo, which subscribes it to the Mailchimp "Spott Newsletter" audience and answers JSON so the visitor stays on the page. The Mailchimp API key stays server-side — a key in page source can read and dump the whole audience. Mailchimp's own embed is no help: /subscribe/post navigates the visitor to a list-manage.com thank-you page, and the JSONP route that kept people on the page is retired on this account (every host 404s, checked 2026-09-24). BOT TRAP: the `b_*` input is a honeypot and must stay in the DOM, empty and off-screen (not display:none — bots read that). A filled one is answered with a cheerful success and written nowhere.
