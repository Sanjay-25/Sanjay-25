Everything you need to know about Omnara, self-hosting, and what you can build.. . What is Omnara? Omnara is an open-source API for running agents in production. The Omnara API handles execution and state while you choose the models, tools, machines, and how users interact with each agent.. How is Omnara different from Claude Managed Agents and other managed agent platforms? Managed agent platforms run your agents on one vendor’s models, machines, cloud, and pricing. Omnara is open source: host the platform on our cloud or yours, use any compatible model, and run agents on any machine, so your agents and their data stay yours.. How is Omnara different from agent frameworks like Vercel’s eve, Mastra, or LangGraph? Agent frameworks are libraries for writing an agent as code and shipping it inside your app, often on one vendor’s gateway, workflow engine, or sandboxes. In Omnara, agents are durable API objects, and the open-source control plane handles state, machines, permissions, and history. Frameworks fit one agent built into your app; Omnara fits many agents you launch and change through an API, without redeploying.. How much does Omnara cost? The platform itself is free. Bring your own model keys and machines at no charge, or pay as you go with Omnara credits for models at provider token rates and machines by active time. Self-hosting is free.. Do I need to run any infrastructure? No. Omnara provides a hosted cloud where the infrastructure (sandboxes, model providers, hosting) is managed for you. You can also self-host Omnara.. Where do agents run? On any machine you choose. Start machines with no provider account and pay for them with Omnara credits, connect your own Blaxel, Daytona, or Unikraft Cloud account, or install the Omnara daemon on a macOS or Linux laptop, VM, or container. The daemon connects outbound, so you never open inbound ports.. Which models are supported? Omnara is model-agnostic and supports OpenAI, Anthropic, OpenRouter, or any compatible endpoint, including models you host yourself.. Is it really open source? Can I self-host? Yes. Omnara is available under the Apache 2.0 license at github.com/omnara-ai/omnara . Omnara Cloud adds managed services. Self-host in your own VPC for full control, or start on the managed cloud and move later.. Do I own my data? Yes. On Omnara Cloud, all data is queryable through the API. To keep it in your own infrastructure, self-host Omnara or book a call and we'll deploy it in your cloud.. Does Omnara support permissions? Tool policies are enforced by the platform. For risky actions, you can configure Omnara to pause for approval.. . . . . . . We handle the infrastructure.. You build the agent.. . Start building Talk to a founder . . . .
