One company domain in, structured latest-stage funding out. 21 programmatic endpoints are ranked on correct stage, latency, and real cost , measured on the same company cohort against source-verified funding events. Crunchbase's and Harmonic's separately measured exports are not API results and are excluded from the API-only recommendations.. Accuracy, speed, and price rarely come from the same provider, so the table shows all three side by side with each endpoint and its public self-serve rate.. In production an endpoint gets asked two different questions. One is about a round from last quarter that should already be in the record. The other is about a round announced this week. Both boards are below, because an endpoint can be dependable on the first and slow on the second, and which one you care about depends on whether you are backfilling a table or reacting to news.. [03] faq. Common questions about calling a funding data API. . What does a funding data endpoint actually return?. One company domain in, and a structured record out: latest funding stage, announced date, round amount, total raised, and round count. The benchmark judges the stage. The other four are recorded and counted for presence, so an endpoint that returns a correct stage with nothing else is visibly different from one that fills the whole record.. . Which funding endpoints can a developer start calling without talking to sales?. Most of the ones listed above. Each row gives the endpoint, the request configuration used, and a link to that vendor's own documentation, so you can check the access terms yourself before writing any code. Two providers on the benchmark are reviewed exports rather than endpoints and cannot be called at all.. . How do I model the cost of a funding API before committing volume?. Start from the billing basis, because the unit differs by vendor: per successful match, per credit consumed, per request made, or per agent run. The estimated cost column scales what each provider actually burned on this cohort, and the docs link on each row gives the current rate and plan floor. A provider that charges only for matches behaves very differently at low match rates than one that charges per request.. . Why does one vendor appear more than once?. Because an endpoint is the thing being measured, and several vendors expose more than one. The same company, the same question and the same output schema go to each endpoint, so the only thing that changes is the endpoint and its configuration.
